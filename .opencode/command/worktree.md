---
description: Crea un worktree con un nombre basado en el contexto proporcionado.
---

Ejecuta el siguiente comando para crear un worktree. El nombre del worktree debe ser un nombre corto en kebab-case derivado del contexto: "$ARGUMENTS"

git worktree add .worktrees/<nombre-del-worktree>

No hagas nada mas. No te cambies de directorio. No ejecutes comandos adicionales.

Si los argumentos son muy largos, simplifícalos a un nombre significativo.
